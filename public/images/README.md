# Images éditoriales

Déposez ici les visuels référencés par chemin direct (hors système de slots
`lib/product-image.ts`).

| Fichier attendu | Où il apparaît |
| --- | --- |
| `founder-story.jpg` | /story, section « 02 · The founder » (portrait éditorial du fondateur / produit, cadré vertical 4:5 conseillé) |

Tant que le fichier est absent, le cadre affiche un bloc porcelaine arrondi
(placeholder). Formats servis tels quels : jpg, webp, avif, png.
